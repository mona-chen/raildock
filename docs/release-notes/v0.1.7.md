A focused fix for PostgreSQL point-in-time recovery: WAL and base-backup uploads no longer fail with an SSH error before the isolated instance is ready.

### Fix

- **Recovery uploads work again.** The host file uploader sent each file chunk inside a `while` modifier whose assignment was parsed too late, so Ruby raised `undefined local variable or method 'chunk' for an instance of HostEngine`. PITR tests and restores use that uploader for WAL archives, so both failed at the SSH step. The loop now assigns the chunk before sending it.
- **Same pattern removed from Dokku imports.** The Dokku file uploader already initialized the variable, but it now uses the same explicit loop so the two paths cannot drift.

### Tests

- New `HostEngine#run_with_file` coverage streams a real temp file through a fake SSH channel and asserts the full payload arrives.
- Full backend suite: 1777 examples, 0 failures. Brakeman clean.
