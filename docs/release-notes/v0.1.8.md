This release adds host package maintenance, native Dokku controls with retained rollback images, an in-container file browser and a Traefik proxy workspace — plus a Puma security bump.

### Highlights

- **Host package maintenance.** Servers now report available Debian/Ubuntu updates without opening SSH from the servers list. Installing requires a reviewed plan, the exact server name and an explicit disruption acknowledgement; the host independently verifies the plan digest, pins reviewed versions, and uses `--only-upgrade --no-remove`. Installs run in a detached systemd unit with bounded progress files, are serialized with a lock, and are never retried automatically, never remove packages and never reboot. OS release upgrades use a guided provider-console flow with snapshot, off-host backup and recovery-console acknowledgements.
- **Native Dokku controls.** RailDock can manage cron entries, startup health checks and predeploy/postdeploy scripts through Dokku's own `app.json` lifecycle, using a versioned plugin that merges a RailDock-owned overlay without executing scripts itself. Registry, log rotation and cron actions are a closed allowlist of named operations; no shell command is accepted from a request.
- **Rollback images that survive deployments.** Each deploy can retain 1–10 images (default 3). The retained copy is a metadata-only relabel under `raildock-history`, so Dokku's pre-deploy `image prune` cannot delete it while the original layers and runtime configuration stay intact. Rollback verifies the exact image ID before use, or explicitly rebuilds the recorded commit with `mode=rebuild`.
- **Service file browser.** A new Files tab browses, previews, downloads and uploads files inside the running app container through fixed `docker exec` commands. Paths are positional arguments, never interpolated into a shell; reads are bounded, uploads cap at 10 MiB and require overwrite confirmation, and writes take the service operation lock. The viewer adds syntax highlighting, line numbers, search, wrap and copy controls plus JSON pretty-printing.
- **Traefik proxy workspace.** The server Proxy tab now combines proxy containers, managed settings, intended routes, certificate inventory and routing warnings. Managed installs get guarded start/stop/restart controls; external installs are never started, stopped or reconfigured. Logs are redacted and bounded, certificate state refreshes on a schedule, and only services actually routed by Traefik appear as routes.
- **Safer project teardown and real-Dokku development.** Project teardown preflights native datastore links before mutating anything, unlinks only owned apps, removes apps before datastores, and treats exact missing resources as safe retries. `make start-real-dokku` / `make connect-real-dokku` add a Lima Ubuntu VM running real Dokku 0.38.34 for end-to-end deploy testing.

### Security

- Puma was updated from 8.0.3 to 8.0.5, clearing two advisories (SSL memory exhaustion and the JRuby proxy path bypass).
- Brakeman is clean; the new host operations keep reviewed plans, typed confirmation and allowlisted commands instead of accepting arbitrary request text.

### Limits worth knowing

- Package maintenance never removes packages, reboots, retries an install or promises rollback. A control-plane outage does not mean apt stopped; unresolved operations stay blocked until reconciled.
- An image rollback restores the application image only, not database data, environment values or release scripts. `mode=rebuild` may produce a different image.
- The file browser writes to the container's writable layer, which is replaced on the next deploy. Persistent files belong in a Storage mount; delete, rename and directory creation are not exposed yet.
- External Traefik mode remains read-only. Stop and restart affect every app behind the proxy and require the exact server name.

### Tests

- Full suites: 1837 backend examples and 225 frontend tests.
- New coverage for reviewed package plans, deployment artifact retention, managed app.json overlays, project teardown, the file browser and viewer, Traefik overview/log redaction, certificate refreshes and native Dokku capabilities.
