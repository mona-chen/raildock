A focused patch for the Agent Access secret dialog: the secret and its setup instructions no longer clip, and the copy button now actually copies on HTTP-served installations.

### Fixes

- **The secret dialog is readable again.** The token, secret and connection details now sit in bounded blocks instead of one long flex row. Long secrets wrap, the dialog no longer scrolls sideways, and the title and description are not clipped at the left edge.
- **Copy works on HTTP.** Browsers hide the async Clipboard API on insecure origins, so RailDock falls back to a selection-based copy. The fallback now runs inside the click's activation window and inserts its scratch element inside the open dialog. Previously the dialog's focus trap stole focus, and the browser reported a successful copy while the clipboard stayed unchanged.
- **Clearer connection details.** The dialog shows the token name, scopes and binding, plus the exact `Authorization`, `X-Organization-ID` and `GET /api/v1/context` lines to use.

### Tests

- Clipboard specs now cover the dialog focus trap, the selected value and insecure-context behavior.
- Full frontend suite: 185 tests; production build passes.
